# Kyaw Zin Thu — Portfolio

A responsive Next.js portfolio prepared for static deployment on Vercel.

## Run locally
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.

## Deploy to Vercel
1. Extract this ZIP and push the project folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Vercel detects Next.js automatically. Keep the default build command `npm run build`.
4. Deploy. The site is configured for static export (`out/`).

## Personalize before publishing
- Update the introduction, skills and project descriptions in `app/page.js`.
- Replace the empty `mailto:` link in the Contact section with your preferred email address.
- Add real project links or social profiles if you want them displayed.
- Review the certificate titles and descriptions. The Burmese academic scans are labelled generically where the exact award text could not be confidently read. The ADBI Cybersecurity certificate is included as a gallery image and downloadable original PDF.\n- The VMU admission is presented as a past admission and scholarship offer, not as a degree earned or an enrolled programme. The full admission notice is intentionally not published to avoid exposing personal information.
- Add a profile photo or CV if desired.

## Certificate images
The supplied certificate scans are stored in `public/certificates/`. They are displayed in the certificate gallery and open in a larger preview when selected.
